먼저 익힐 흐름

색 맞는 2리듬 → 2리듬 → 애드리브 1리듬

  1. 리듬 만들기

    색이 맞는 스킬의 2리듬과 애드리브의 1리듬을 이용해 2+2+1로 템포를 채우는 10월 제보입니다.

  2. 색에 맞춰 우선 사용

    파랑에서는 5, 빨강에서는 3 발걸음을 우선하는 제보입니다. 1·2·4는 이동·브레이크 상황까지 보고 사용합니다.

  3. 환호 마무리

    앵콜 직전에 4로 멀어지지 않도록 주의합니다. 환호의 마무리 때 잡몹이 있으면 공격이 분산될 수 있다는 제보를 함께 봅니다.

  4. 자동 대안

    2·4를 끄는 과거 자동 운용안이 있습니다. 손컨보다 좋았다는 일부 드릴 사례를 모든 난이도의 자동 우위로 일반화하지 않습니다.

번호는 아래 자료의 스킬 배치를 따릅니다. ‘평’은 평타, 괄호는 조건부 입력입니다. 자동·수동·짧은 전투 예시는 동일한 성능 보장이 아닙니다.
