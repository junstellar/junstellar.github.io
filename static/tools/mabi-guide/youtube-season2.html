🌑 암흑술사 “절구나” 딜사이클 — 나락은 잠식 0일 때

  • 절구나 = 절제 + 구속 + 나락. 절제(1번)는 쿨마다, 구속 사슬(3번)은 자주 굴릴수록 좋다.
  • 나락(4번)은 시전 시 잠식되며 생성한 잠식 수치에 비례해 위력이 오른다 → 잠식 게이지가 0에 가까울 때 써야 0→100 상승분을 온전히 챙긴다. 쿨마다 기계적으로 쓰는 스킬이 아니다.
  • 스타트는 4 → 3 → 빙의 → 3 → 5 → 2 → 1이 거의 고정(이전에 안내됐던 빙의 후 2번 순서는 오류로 정정됨).
  • 2번 대신 3번을 먼저 쓰는 이유: 2번은 잠식 +25로 그림자 1기, 3번은 잠식 +50으로 2기 소환. 2기면 타수가 2배라 패시브 재물의 낙인 40중첩을 빨리 채워 검은 창 쿨이 당겨진다. 추가타가 높으면 2번 스타트로도 돌아간다.
