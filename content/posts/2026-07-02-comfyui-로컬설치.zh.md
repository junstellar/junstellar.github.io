Claude 是文本 AI，自己没法画画。但**只要给它接上一个跑在本地电脑上的图像生成服务器**，一句「画只猫」就能让 Claude 把提示词打磨好、把图画出来。今天就把在游戏本（RTX 4060）上安装 ComfyUI + SDXL、真正搭起这套东西的过程整理一下。成本 0 元，不联网也能跑。

## 用哪个工具来画 —— 三个选项

- **Automatic1111 WebUI（本地）** —— 传统的 Web UI，自己上手最简单，但内存管理松散，8GB 显存跑 SDXL 很吃力。
- **Nano Banana（云端，Gemini API）** —— 不用安装，有 API 密钥就行，质量也不错，但每张约 50 韩元 + 必须联网 + 会打水印。
- **ComfyUI（本地）← 最终选择** —— 节点式 UI 有点陌生，但反正是 Claude 通过 API 调用，无所谓。三个候选里它**显存效率最好**（对 8GB 笔记本很关键），整套工作流都是 JSON，所以**程序调用起来最干净**，而且免费、无限量、离线可用。

## 整体结构

核心思路很简单。Claude 只负责「指挥」，画图交给本地 GPU。

```
用户：「画一张夕阳下的首尔夜景」
   ↓
Claude：韩语请求 → 转换、补强成英文提示词
   ↓
ComfyUI 服务器（本地，http://127.0.0.1:8188）
   ↓
SDXL 模型在 RTX 4060 上生成图像（20~40 秒）
   ↓
Claude 把生成好的 PNG 显示在聊天里
```

- **ComfyUI**：运行 Stable Diffusion 的开源程序。它提供 REST API，外部程序（Claude）可以调用。
- **SDXL**：Stability AI 的图像生成模型。1024×1024 原生分辨率。

## 我的电脑跑得动吗？—— 配置确认

安装前确认的最低要求，以及我笔记本（HP Victus 16）的配置：

| 项目 | 所需配置 | 我的笔记本 | 判定 |
|---|---|---|---|
| GPU 显存 | 建议 8GB 以上（SDXL） | RTX 4060 Laptop 8GB | 通过 |
| 内存 | 16GB | 16GB | 通过 |
| 磁盘 | 约 20GB | 351GB 剩余 | 通过 |

8GB 显存是 SDXL 事实上的底线。6GB 及以下的话，用更轻的 SD 1.5 模型更合适。

## 安装过程（以 Windows 11 为例）

### 1. 克隆 ComfyUI + 虚拟环境

```powershell
git clone --depth 1 https://github.com/comfyanonymous/ComfyUI C:\ComfyUI
python -m venv C:\ComfyUI\venv
```

### 2. 安装 PyTorch（CUDA 版）

普通的 `pip install torch` 装的是 CPU 版，所以要用 GPU **必须指定 CUDA 索引**。

```powershell
C:\ComfyUI\venv\Scripts\python.exe -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
```

安装后，确认 GPU 已被识别：

```powershell
C:\ComfyUI\venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available())"
# 应当输出 True
```

### 3. 依赖 + 下载 SDXL 模型

```powershell
C:\ComfyUI\venv\Scripts\python.exe -m pip install -r C:\ComfyUI\requirements.txt

# SDXL base 模型（~6.5GB） → 保存到 models\checkpoints\
curl.exe -L -o C:\ComfyUI\models\checkpoints\sd_xl_base_1.0.safetensors https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/resolve/main/sd_xl_base_1.0.safetensors
```

### 4. 启动服务器

```powershell
C:\ComfyUI\venv\Scripts\python.exe C:\ComfyUI\main.py --port 8188
```

在浏览器里打开 `http://127.0.0.1:8188` 会出现节点式 UI，但如果目的是对接 Claude，基本不用直接去碰这个 UI。

## 与 Claude 连接

ComfyUI 的 API 有两个核心端点。

- `POST /prompt` —— 提交工作流（JSON），它会返回一个 `prompt_id`
- `GET /history/{prompt_id}` —— 生成结束后，会带回结果图像的文件名

我写了一个调用它们的 Python 脚本（`generate.py`），并在 Claude Code 里注册了一个**技能（skill）**。技能就是一份指令书，写着「来了这样的请求，就执行这个脚本」：

```markdown
---
name: draw-local
description: 用户请求画图时用本地 ComfyUI 生成。韩语提示词翻译成英文。
---
C:\ComfyUI\venv\Scripts\python.exe C:\ComfyUI\generate.py "PROMPT"
执行后，若输出 SAVED <路径>，就把那个 PNG 显示在聊天里。
```

这样一来，只要对 Claude 说「画……」，它就会自己搞定：① 服务器没开就自动启动 → ② 把韩语翻译、补强成英文提示词 → ③ 生成 → ④ 把图显示在聊天里。

### 示例 3 —— 真实地点 + 时间段 + 风格


**提示词小技巧**：① 用英文写（SDXL 的训练数据里英文占绝对多数）。② 把 `photorealistic`、`cinematic lighting` 这类风格关键词加在后面。③ 想避免的元素，用负面提示词（`blurry, low quality, watermark...`）单独分出来。

## 实测性能（RTX 4060 Laptop, 8GB）

- 首次生成：约 1 分钟（含服务器启动 + 把模型加载进显存）
- 之后：**每张 20~40 秒**（1024×1024，28 步）
- 把步数降到 20 约 24 秒，质量差别不大

## 小结

- 8GB 显存的笔记本，本地跑 SDXL 生成已经相当实用。
- 对接 Claude 的核心就两样：「调用 ComfyUI API 的脚本 + 注册一个技能」。
- 相较云端 API（Nano Banana 等）的优点：免费、无限量、离线。缺点：质量和文字渲染上，云端模型更占优。
