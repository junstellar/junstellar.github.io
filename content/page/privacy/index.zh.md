**To the Moon**（以下简称"本博客"，`https://junstellar.github.io`）重视访问者的个人信息，并在此透明地说明收集和使用哪些信息。

## 1. 收集的个人信息

本博客是托管在 GitHub Pages 上的静态网站，**没有注册、登录或评论功能。** 因此，本博客**不会直接收集**姓名、电子邮箱、电话号码等**可识别个人身份的信息。**

如果您通过下方"联系方式"中的邮箱直接联系我们，邮件中包含的信息（邮箱地址、咨询内容）仅用于回复您的咨询，不会另行存储或共享。

## 2. 访问统计（GoatCounter）

本博客使用注重隐私保护的分析工具 **GoatCounter** 来了解访问情况。GoatCounter：

- **不使用 Cookie**，也不识别个人身份。
- 仅收集访问页面、访问国家/地区、浏览器、来源渠道等**匿名的汇总统计数据**。
- IP 地址仅临时用于防止重复统计等目的，不会以可识别的形式存储。

详情请参阅 [GoatCounter 隐私政策](https://www.goatcounter.com/help/privacy)。

## 3. Cookie 与广告（Google AdSense）

本博客可能通过 **Google AdSense** 展示广告。就此说明如下：

- 包括 Google 在内的**第三方广告供应商**会使用 Cookie，根据用户对本博客及其他网站的访问记录投放个性化广告。
- Google 使用广告 Cookie（例如 **DoubleClick Cookie**）来投放基于用户兴趣的广告。
- 您可以在 [Google 广告设置](https://www.google.com/settings/ads)中**停用个性化广告**。
- 如需拒绝第三方供应商使用 Cookie，可在 [www.aboutads.info](https://www.aboutads.info/choices/) 选择退出。

关于 Google 广告及数据处理的详细信息，请参阅 [Google 广告隐私政策](https://policies.google.com/technologies/ads)。

## 4. 如何拒绝 Cookie

您可以通过浏览器设置拒绝保存 Cookie。但如果拒绝 Cookie，部分广告可能会显示为非个性化的一般广告。

- **Chrome**：设置 → 隐私和安全 → Cookie 及其他网站数据
- **Edge**：设置 → Cookie 和网站权限
- **Safari**：偏好设置 → 隐私
